# Third-party code

`ug2map/static/three.min.js`, `OrbitControls.js` and `TransformControls.js` are part of [three.js](https://threejs.org/) (MIT License, Copyright © three.js authors). They are included unmodified so that the viewer works without internet access.

Python dependencies: [NumPy](https://numpy.org/) (BSD) and [Pillow](https://python-pillow.org/) (HPND).

The file format notes build on the community's reverse-engineering of the NFS engine files; thanks to everybody who documented them.
